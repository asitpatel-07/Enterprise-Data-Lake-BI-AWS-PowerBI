# Enterprise Data Lake and Business Intelligence Solution Using AWS and Power BI

## Project Overview
This project implements a cloud-based retail data analytics solution using AWS services and Microsoft Power BI.

## Technologies Used
- Amazon S3
- AWS Glue Crawler
- AWS Glue Data Catalog
- Amazon Athena
- Athena ODBC Driver
- Microsoft Power BI
- SQL

## Architecture
Retail CSV Dataset → Amazon S3 → AWS Glue Crawler → Glue Data Catalog → Amazon Athena → ODBC → Power BI Dashboard

## Dataset
The project uses retail sales data containing customer details, product information, quantity, unit price, region, and total sales amount.

## Key Results
- Total Orders: 50
- Units Sold: 121
- Total Revenue: ₹12,31,200

## Features
- Cloud-based data storage
- Automated schema discovery
- SQL-based analytics
- Interactive Power BI dashboard
- Revenue and sales performance analysis
